# Design Team

Your AI design crew that ships. Not just pretty pictures -- research, strategy, copy, design, code, review, deploy.

## Install

```bash
# Install the full skill set
npx skills add pablostanley/designteam-app

# Or install a custom team by ID
npx designteam install abc123
```

## What you get

- **23 agent roles** with distinct specialties, philosophies, and proficiencies
- **Personality system** -- 5 bipolar sliders (-5 to +5), 32 traits across 4 categories
- **AI team builder** -- describe your project, get a team with roles, personalities, and traits
- **7 team presets** -- Landing Page Sprint, Brand Campaign, Content Machine, and more
- **Team tension dynamics** -- productive friction between agents (perfectionist vs fast-shipper)
- **Export** -- Markdown (with generated skill files per agent) and JSON
- **Works with** Claude Code, Cursor, Codex, Windsurf, and any skills.sh-compatible tool

## Visual team builder

Build and customize your team at [designteam.app](https://designteam.app)

### Personality system

Every agent has 5 personality sliders (-5 to +5) and up to 4 selectable traits:

**Sliders:** Bold/Subtle, Playful/Serious, Experimental/Conventional, Verbose/Concise, Warm/Corporate

**Traits (32 total across 4 categories):**
- **Temperament:** sassy, chill, intense, nurturing, provocative, deadpan, enthusiastic, stoic
- **Work Style:** perfectionist, fast-shipper, big-picture, detail-obsessed, methodical, chaotic-creative, iterative, one-shot
- **Social:** extrovert, introvert, leader, collaborator, independent, mentor, challenger, supporter
- **Mindset:** thinking, feeling, judging, perceiving, optimist, realist, risk-taker, cautious

Traits create team dynamics. A perfectionist paired with a fast-shipper creates healthy Quality vs Speed tension.

### AI team builder

Describe your project and let Claude build your team:

```
"A SaaS landing page for a fintech startup"
"A complete rebrand for a sustainable fashion brand"
"Social media campaign for a product launch"
```

Claude picks the right roles, tunes personalities, assigns traits, and writes custom prompts for each agent.
